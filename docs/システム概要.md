## システム構成

- **人**
  - 話しかける人：スピーカーフォンに声で話しかける。深度カメラが顔と姿を見る
  - スマホ / PC（補助）：入力ページ `/remote` から文字入力・手動操作
- **台車（律の体）**
  - Arduino UNO Q
    - Linux 側（Debian）
      - Chromium kiosk：画面の律（three.js + VRM）、会話の頭（brain.js）、声（voice.js）
      - Docker Compose
        - nginx：画面の配信、サーバーへの中継（API キーを付ける）
        - rosbridge：ブラウザと ROS 2 をつなぐ
        - ritsu_perception：見る（顔・人・障害物・フォローの人の追跡）
        - ritsu_memory：覚える（記憶・反応の記録・ニュース）
        - ritsu_base：動く（向く・少し動く・おさんぽ・フォロー・安全装置）
    - マイコン側（STM32U585）：4輪の速さ制御
  - USB 機器：深度カメラ Orbbec Gemini 335、スピーカーフォン Anker PowerConf、縦置きモニター
  - 足回り：L298N ×2 → メカナム車輪 ×4（エンコーダー付きモーター）、LiPo バッテリー
- **サーバー（GPU）**
  - LiteLLM → Ollama（gemma3:4b / 12b）：考える
  - faster-whisper：聞き取り
  - VOICEVOX ENGINE：読み上げ
- **外部サービス**：Open-Meteo（天気）、Yahoo!ニュース RSS（見出し）

**つながり**

- 声：スピーカーフォン ⇔ 画面の律 → nginx → Whisper（文字にする）/ LiteLLM（返事を考える）/ VOICEVOX（声にする）
- ROS 2：画面の律 ⇔ rosbridge ⇔ ritsu_perception・ritsu_memory・ritsu_base
- 台車：ritsu_base → Bridge（MessagePack-RPC）→ STM32 → L298N → モーター → エンコーダー → STM32

**フィジカルAI の流れ**：深度カメラで見る（ritsu_perception）→ Jev 風に判断する（LLM の7択 / walk_decide・follow_decide）→ 台車が動く（ritsu_base → STM32 → モーター）

## 使用した技術

- **ROS 2 Jazzy**：ノード間のトピック通信（人の位置・障害物・台車の指令）
- **rosbridge_suite / roslib.js**：ブラウザと ROS 2 を WebSocket でつなぐ
- **Docker / Docker Compose**：nginx・rosbridge・ROS 2 ノードを個別のコンテナで動かす
- **nginx**：画面の配信、LLM・音声サーバーへの中継（API キーの付与）
- **three.js / @pixiv/three-vrm**：VRM キャラクターの表示・モーション・表情・視線
- **OpenCV（YuNet / SFace）**：顔の検出、マスターの顔の見分け
- **NumPy / OpenCV**：床の推定（RANSAC）、障害物の検出、人の追跡（上から見た地図とかたまり）
- **Ollama（gemma3:4b / gemma3:12b）**：会話、独り言、反応の決定、記憶の要約
- **Jev 風の選択肢判断（JSON Schema の enum）**：あいまいな動く頼みを7択で1語だけ答えさせる
- **faster-whisper（large-v3-turbo）**：声を文字にする
- **VOICEVOX ENGINE（WhiteCUL）**：律の声
- **Web Audio API（AudioWorklet）**：マイクの取り込み、声の区間の切り出し、口パク
- **Arduino（Zephyr）/ Arduino_RouterBridge**：4輪の速さの PI 制御、エンコーダー、Linux 側との通信
- **Python / JavaScript / C++（Arduino）**：ROS 2 ノード / 画面と会話 / マイコン

## API

- **LiteLLM（OpenAI 互換 Chat Completions API）**：LLM を呼ぶ。ストリーミングで最初の文から話し始める。JSON Schema で答えを選択肢に縛る
- **Ollama**：LiteLLM の後ろで gemma3 を動かす
- **faster-whisper（自作の HTTP サーバー）**：音声を送って文字にする
- **VOICEVOX ENGINE API**：audio_query → synthesis で声を作る
- **Open-Meteo Forecast API**：天気を会話の「今の状況」に入れる
- **Yahoo!ニュース・トピックス RSS**：最近のニュースの見出しを話題にする
- **rosbridge WebSocket（JSON）**：ブラウザから ROS 2 トピックを送る・受ける
- **Arduino RouterBridge（MessagePack-RPC）**：Linux 側から STM32 の base_set / base_pwm を呼ぶ
- **Orbbec SDK（pyorbbecsdk）**：深度カメラのカラー・深度・IMU を受け取る
- **Web API（getUserMedia / AudioWorklet）**：ブラウザでマイクを使う

## ツール

- **Arduino App Lab**：STM32 のスケッチの書き込みと自動起動
- **Chromium（kiosk モード）**：縦置きモニターに律を全画面表示
- **Proxmox VE（LXC）**：LiteLLM・音声サーバーを動かすコンテナ
- **systemd**：LiteLLM・Whisper・VOICEVOX をサービスとして動かす
- **Git / GitHub**：ソース管理と UNO Q への配置
- **WSL2 / usbipd-win**：開発 PC で深度カメラを使って試す
- **Mermaid / Playwright**：構成図・アクティビティ図を描いて PNG にする
- **Claude Code**：設計・実装・デバッグ・文書作成

## デバイス

- **Arduino UNO Q（Qualcomm QRB2210 ＋ STM32U585）**：Linux 側で見る・考える・話す、マイコン側で車輪を回す
- **Orbbec Gemini 335（深度カメラ）**：顔・人・障害物・傾き（カラー・深度・IMU）
- **Anker PowerConf（スピーカーフォン）**：耳と口（マイク ＋ スピーカー）
- **縦置きモニター（USB-C / DisplayPort）**：画面の律
- **セルフパワー USB-C ハブ**：カメラ・スピーカーフォン・映像出力
- **L298N ×2（モータードライバー）**：左右の車輪の駆動
- **Yahboom 520 ×4（12V・1:40・ホール式エンコーダー付きモーター）**：メカナム4輪
- **メカナムホイール ×4**：向きを変えずに横へ動く（フォローでよける）
- **LiPo バッテリー 12〜13V**：モーターの電源
- **GPU サーバー（Proxmox 上の LXC コンテナ ＋ Ollama を動かす PC）**：LLM・音声認識・音声合成
