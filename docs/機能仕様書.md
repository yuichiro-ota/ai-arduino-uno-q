## 1. 概要

### 1.1 目的

縦置きモニターに映る VRM キャラクター「律」が、声で会話し、深度カメラで人を見て反応し、メカナム4輪の台車で動く。
「見る → 判断する → 体を動かす」を実世界で行う、小さなフィジカルAIとして作る。

### 1.2 システムの範囲

| 区分 | 含むもの |
|---|---|
| 台車（律の体） | Arduino UNO Q（Linux 側・マイコン側）、深度カメラ Orbbec Gemini 335、USB スピーカーフォン、縦置きモニター、L298N ×2、エンコーダー付きモーター ×4、バッテリー |
| サーバー | LiteLLM → Ollama（gemma3:4b / 12b）、Whisper（文字起こし）、VOICEVOX ENGINE（読み上げ） |
| 補助の端末 | スマホ・PC のブラウザで開く入力ページ `/remote` |

### 1.3 用語

| 用語 | 意味 |
|---|---|
| 画面の律（kiosk） | UNO Q の Chromium で全画面表示している律の画面。会話の判断（brain.js）もここで動く |
| 入力ページ（/remote） | スマホ・PC から文字で話しかけたり、台車を手で動かしたりする補助のページ |
| マスター | 顔を登録した人。律は親しく話し、その人のことを覚える |
| Jev 風 LLM | 4-link-robot の Jev と同じく、LLM の答えを選択肢に縛って1語だけ答えさせる判断。速く、答えがぶれない |
| Jev と同じ形のルール判断 | Jev と同じ入出力（障害物 → FORWARD / LEFT / RIGHT / WAIT）をルールで決めるもの。あとで local-jev などの LLM に差し替えられる |
| フィジカルAI | 深度カメラで見る → Jev 風に判断する → 台車が動く、の一連の流れ |

### 1.4 利用者

| 利用者 | 主な使い方 |
|---|---|
| 来た人・話しかける人 | 律の前に立つ、声で話しかける、「ついてきて」などで台車を動かす |
| マスター | 上に加えて、顔の登録、覚えたことの確認・修正 |
| 管理者 | 起動・更新・設定（`.env`、`config.js`）、ログの確認 |

## 3. 機能詳細

### F-01 声で会話する

| 項目 | 内容 |
|---|---|
| きっかけ | スピーカーフォンに向かって話す |
| 動作 | 声の区間を音量で切り出し → Whisper で文字にする → 言葉の種類を見分ける（F-30〜F-32 の動く頼み・F-03・それ以外）→ それ以外は LLM が返事を作る → 字幕と VOICEVOX の声で話し、表情・モーションを付ける |
| 応答の目安 | 話し終わりから文字になるまで約1〜1.5秒。最初の文ができたらすぐ話し始める |
| 相槌 | 相手が話している間は小さくうなずき、話し終わったら「うんうん」などの相槌（先に作っておいた声）。返事に時間がかかると「えっと……」 |
| 割り込み | 律が話している途中でも、はっきりした声が約0.26秒続くと律の声を止めて聞く |
| 聞かない間 | 返事を考えている間と、動く頼みの返事・おさんぽ/フォローの始め・終わりの言葉を言っている間（F-38） |
| 呼びかけ | 「律ちゃん」「りっちゃん」どちらでも自分のことと分かる |
| 声で話すのは | kiosk 画面だけ |

### F-02 文字で会話する

- `/remote` の入力欄、または画面のキーボードから話しかけると、F-01 と同じ流れで返事をする（声の切り出し・文字起こしは無い）。
- `/remote` から話しかけたときは、話している独り言を止め、独り言・反応の LLM 問い合わせを打ち切って、返事を先にする。
- `/remote` から話しかけたときは、台車は向かない（目の前の人とは限らないため）。
- 返事は話しかけた全員の `/remote` の履歴に出る。声で聞き取った言葉は「声で」と出る。

### F-03 静かにする / 話していいよ

- 「静かに」「黙って」「うるさい」などで、5分間は自分からしゃべらない（独り言・挨拶などの反応は動きだけ）。話しかけられたら答える。
- 「話していいよ」「もういいよ」などで取り消す。画面左上のスピーカーの絵を押しても切り替えられる。

### F-04 状況に合わせた独り言

- LLM に渡す「今の状況」: 日時・時間帯・季節・平日/土日/祝日（振替休日を含む）・季節の行事・天気（Open-Meteo）・カメラの前の人の距離・最近のニュース。
- 会話が無い間は約10〜20秒に1回しゃべる。そのうち約3分の2は LLM が状況から毎回違う独り言を作り、残りは用意したセリフから選ぶ。
- 会話が無いと1〜2分に1回、カメラが目元まで寄ってのぞき込む。
- おさんぽ中・フォロー中・静かにしているときは独り言を言わない。

### F-05 最近のニュースを話す

- memory ノードが30分ごとに Yahoo!ニュース・トピックスの見出しを取り、事件・事故・災害などの暗い見出しを除いて律に渡す。
- 聞かれたら答え、独り言でもときどき話題にする。見出しに無いことは推測で話さない。

### F-10 目線で人を追う

- 深度カメラで顔（両目の中点）の3次元の位置を測り、律の目線と体の向きをその人へ向ける。

### F-11 目が合った人・来た人への反応

| きっかけ | 反応 |
|---|---|
| 人が来た | 時間帯に合った挨拶 |
| 目が合った（顔がこちらを向いている） | 挨拶。通り過ぎるだけの人には話しかけない |
| こちらを見ながら近づいてくる | 嬉しそうに跳ねる・手を振る |
| しばらく居てくれる | 声かけ（動きだけ / 一言 / 質問） |
| マスターが来た | 親しく挨拶。知らない人として挨拶したあとで気づいたら「あっ、マスターでしたか」 |

- 何を言うか・どう動くか・何もしないかは、LLM が状況と記憶を見て決める。4秒以内に答えが無ければ用意したセリフにする。
- 反応すると決めたときは、話しながら台車ごと人の方を向く（F-33）。

### F-12 体の反応

| 反応 | 条件 |
|---|---|
| 迎える | こちらを見ながら近づいてくる |
| のぞき込む | 見ていた人が一番近づいたところから約50cm下がる（1分に1回まで） |
| ガラスに手 | 画面のすぐ前（45cm以内）に手を出すと、律も内側から同じ高さ・位置に手を合わせる |
| よろける | カメラが左右に15度以上傾くと「おっとっと」（8度未満に戻るまで再発動しない） |
| 姿勢合わせ | すぐ目の前の人には少しのけぞり、離れて見ている人には身を乗り出す |
| 振り向く | 物音に振り向く |

LLM を待たずにすぐ動く。

### F-13 マスターの顔を見分ける

- `/remote` の「マスター登録」で顔を登録する（約4秒で6枚、最大60枚分）。顔の画像は保存せず、見分けるための数値だけを UNO Q の `data/faces/` に保存する。
- 70px 以上の大きさの、ほぼ正面の顔を1秒に1回見分ける。フォロー中は処理を軽くするため休む。

### F-20 会話の記憶

- 今日来た人・目が合った人・話してくれた人の数、話した人との会話の要約（LLM が1文にまとめる）、マスターとの会話の要約と前回会った日を `data/memory.json` に残し、会話に使う。
- ほかの人やマスターとの会話の中身は、マスター以外には話さない。次の人に前の人との会話は引き継がない。
- 保存のたびに控えを残し（14日分）、`memory.json` が壊れていたら起動時に一番新しい控えから戻す。

### F-21 律自身のこと・マスターのことを覚える

- 会話が途切れて LLM が空いているときに、「律が自分について言ったこと」（律 24件まで）と「マスターが自分について言ったこと」（20件まで）を抜き出して覚え、毎回プロンプトに入れる。同じことを聞かれたら前と同じ答えにする。
- `/remote` の「覚えたこと」で見る・直す・消す・足すができる。

### F-22 言葉を教える・訂正する

- 「〇〇っていうのは△△のことだよ」で言葉と意味を覚える（40個まで）。話に出てきた言葉だけ意味までプロンプトに入れる。
- 「AじゃなくてB」「〇〇は△△だよ」の形は LLM を使わずに直す。それ以外の訂正は LLM にどれをどう直すか1行で答えさせる。

### F-23 反応の学習

- 挨拶と声かけのやり方ごとに、そのあと30秒のうちに話しかけてくれたか・どれだけ居てくれたかを `data/log/日付.jsonl` に記録する。
- 結果のよいやり方を多めに選ぶ（2割は試しに別のやり方）。マスターへの反応は数えない。

### F-30 止まる

- 「止まって」「停止」「ストップ」（前に呼びかけが付いてもよい）で、少し動く・人の方を向く・おさんぽ・フォローを全部すぐやめる。
- LLM を通さず、返事を考えている途中でも順番待ちを飛ばす。
- `/remote` の赤い **停止** ボタンは、律を通さず台車へ直接止める指示を送る（声より速い）。

### F-31 決まった頼みで少し動く

| 頼み方（例） | 動き |
|---|---|
| 「前に来て」「前進して」「進んで」 | 15cm 前へ |
| 「ちょっと後ろに下がって」「後退して」「バックして」 | 15cm 後ろへ |
| 「左向いて」「右向いて」 | 律から見て左・右へ30度回る |

- LLM を使わずすぐ返事をして、ゆっくり動く。動いた量はエンコーダーで測って止め、測れなくても時間で止まる。
- 目の前の人が60cmより近いときは前に出ない。20文字までの短い頼み方だけ（質問の形は普通の会話として答える）。

### F-32 あいまいな頼みを聞き分けて動く（★ Jev 風 LLM）

- 決まった言い方でなくても（「もうちょい前」「少し離れてくれる」「こっちおいで」「左側見て」など）、動きの手がかりがあって頼む言い方で終わる30文字までの言葉は、LLM に7択で1語だけ答えさせる。
- 選択肢: FORWARD（前）・BACK（後ろ）・LEFT（左）・RIGHT（右）・FACE（こっち）・STOP（止まる）・NONE（関係ない）。
- 約0.3〜0.7秒で決まる。2.5秒で答えが無いときと NONE は普通の会話として答える。
- 手や首の動き（「右手を上げて」）や「後ろ向いて」は聞き分けにかけない。

### F-33 人の方を向く・「こっち向いて」

- 律が反応すると決めたときと声で話しかけられたときに、台車がその場で回って相手を正面にとらえる。
- 正面から5度以内に入ったら止まる。頼まれたときのずれが10度以内なら回らない（目線だけで追う）。顔を見失う・8秒たつ・十字ボタンで動かすとやめる。回る速さは最大 0.4rad/s。
- 「こっち向いて」は、ずれが小さくても正面まで向き直る。顔が見えなければ最後に顔を見た側へ回って探す（最大150度）。

### F-34 障害物で前進を止める（安全装置）

- カメラが前方の障害物までの距離を「正面（台車の通り道）・左・右」に分けて出し、正面の物が0.4mより近い間は、**前に進む指令だけ**止める（回る・下がるはできる）。
- 十字ボタン・少し動く・おさんぽ・フォロー、どの動きでも最後に必ず通る。
- 頼まれた前進を止めたときは、律が「前に何かあって、これ以上進めません。左のほうは空いています。」のように空いている側を知らせる。
- 見えるのは前方の画角だけ。後ろと、カメラより低くて近い物は見えない。

### F-35 おさんぽモード（☆）

| 項目 | 内容 |
|---|---|
| 始め方 | 「おさんぽ」（一言だけでも）「お散歩して」「おさんぽモード」「歩き回って」、または `/remote` の「おさんぽ」をオン |
| 動き | 1分間ゆっくり（0.08m/s）前に進み、正面0.7m以内に物が見えたら、その場で空いている方へ回る。正面が空いたらまた進む |
| 判断 | `walk_decide`: 障害物（前・左・右）→ FORWARD / LEFT / RIGHT |
| やめる | 「止まって」「お散歩おしまい」・スイッチをオフ・十字ボタン・1分たつ・200度回っても正面が空かない・カメラの知らせが5秒途切れる |
| 律の言葉 | 始め「わーい、お散歩してきます。」、時間で終わり「お散歩おしまいです。楽しかったです。」など |

### F-36 フォローモード（☆）

| 項目 | 内容 |
|---|---|
| 始め方 | 「ついてきて」「フォローして」「一緒に来て」、または `/remote` の「フォロー」をオン |
| 人の決め方 | 顔が見えればその真下、見えなければ正面30度・3.5m以内でいちばん近い「人くらいの大きさ」（幅15〜90cm・床から0.9mくらいまで届く）の深度のかたまり |
| 動き | 人の方を向きながら、0.7m あけて最大0.15m/sでついていく。0.8mより近ければ止まって待つ。人が大きく横に動いたら先に向きを合わせる |
| 判断 | `follow_decide`: 人を除いた障害物 → FORWARD / LEFT / RIGHT / WAIT。間に物があれば空いている側へ向きを変えずに横へよける（メカナム） |
| 見失ったとき | その場で待つ。4秒見つからなければやめて「見失ってしまいました」 |
| 人が決まらないとき | 5秒で「ついていく人が見つかりません。律のほうを向いて、前に立ってから、もう一度言ってくださいね。」 |
| やめる | 「止まって」「もうついてこなくていいよ」・スイッチをオフ・十字ボタン・おさんぽを始める・5分たつ・カメラの知らせが5秒途切れる |
| 狭い部屋 | 人と家具・壁が1つのかたまりにつながるので、顔の真下や前の位置のまわり22cmだけを見て人を決める。始めるときは律のほうを向く（顔を見せる）。8秒確かめられなければ見失ったとみなす |

### F-37 手で動かす

- `/remote` の十字ボタンを押している間だけ動く（前・後・左・右・その場で回る）。離すか画面を閉じると止まり、指令が0.5秒届かなければ台車側でも止まる。
- 十字ボタンを触ると、向く・少し動く・おさんぽ・フォローはやめる。
- 「1輪ずつ試す」で各車輪を1秒だけ回し、配線と向きを確かめる。

### F-38 動いている間の話し方

- おさんぽ中・フォロー中は、独り言と、しばらく居てくれる人への声かけをしない。話しかけられたら答える。
- 動く頼みの返事と、おさんぽ・フォローの始め・終わりの言葉は最後まで言う。その間（読み上げにかかる時間の見込み: 1.2秒 ＋ 1文字0.17秒）は聞かず、独り言・反応もしない。モーターの音を声と間違えて割り込まないため。
- おさんぽ・フォローが終わったあと5秒も独り言・反応をしない。

## 4. 非機能要件

| 区分 | 要件 |
|---|---|
| 応答時間 | 止まる（F-30）は LLM を通さずすぐ。少し動く（F-31）は LLM を使わずすぐ返事。あいまいな頼み（F-32）は約0.3〜0.7秒、2.5秒で打ち切り。人への反応（F-11）は4秒で打ち切り |
| 安全 | 正面0.4mの安全装置はすべての動きで働く。指令が0.5秒来なければ台車のノードとマイコンの両方で止まる。モーターが強く回しているのに1秒回らないときは止める。PWM は220まで |
| プライバシー | 顔は画像を保存せず数値だけを UNO Q の `data/` に置く。記憶・ログも UNO Q の中だけ（Git の管理外）。マスターとの会話はマスター以外に話さない |
| 秘密情報 | LiteLLM のキーは UNO Q の `.env` にだけ置き、nginx が中継のときに付ける（ブラウザに渡さない） |
| 復旧 | ブラウザと rosbridge は自動で再接続する。カメラは10秒映像が来なければ開き直す。カメラの処理が30秒進まなければプロセスを終了し、Docker が起動し直す |
| 処理能力 | UNO Q の上でカメラの処理は1秒に数回（約1〜4回）。重い AI（LLM・文字起こし・読み上げ）はサーバーの GPU で動かす |

## 5. 制約・既知の制限

- 深度カメラは台車の低い位置（約0.4m）にあるため、近くに立つ人の顔は画角の上に出て見えない。狭い部屋でフォローを始めるには、顔を見せる（かがむ・少し離れる）必要がある。
- フォローは、人が柱や壁・別の人にぴったり並ぶと取り違えることがある。急に横へ走ると見失う。
- 後ろは見えないので、下がる動きは「少し動く」だけで、おさんぽ・フォローでは下がらない。
- `/remote` は LAN 内の誰でも開けるので、顔の登録ボタンも誰でも押せる。
- Yahoo!ニュースの RSS は個人での利用を想定したもの。
