## 1. 画面一覧

| ID | 画面 | URL | 使う人・場所 |
|---|---|---|---|
| SC-01 | 律の画面（kiosk） | `http://localhost:8080/?kiosk=1&lite=1` | UNO Q の縦置きモニターに全画面で表示（`kiosk/ritsu-kiosk.sh` が起動） |
| SC-02 | 入力ページ | `http://<UNO Q の IP>:8080/remote` | スマホ・PC のブラウザ（複数台で同時に使える） |
| SC-03 | 確認用カメラ画像 | `http://<UNO Q の IP>:8080/debug/camera.jpg` | 管理者（`DEBUG_SNAPSHOT=1` のときだけ） |

SC-01 と SC-02 は画面の遷移でつながらず、ROS 2 のトピック（rosbridge）でやり取りする。

```
SC-02 入力ページ ──/ritsu/chat_user・/cmd_vel・/ritsu/walk・follow・turn・enroll──▶ 律・台車・カメラ
                 ◀──/ritsu/say・thinking・voice_status・base_status・enroll_status──
SC-01 律の画面   ◀──/ritsu/person・looking・memory・base_event ほか──  ROS 2 ノード
```

## 2. SC-01 律の画面（kiosk）

### 2.1 レイアウト（縦置き）

```
┌───────────────────────────┐
│ (1)LLM (2)ROS (3)CAMERA     │
│ (4)MIC (5)🔊話す             │
│                             │
│                             │
│       (6) 律（VRM）          │
│        背景・桜の花びら      │
│                             │
│                             │
│  ┌──────────────────┐  │
│  │ (7) 字幕（吹き出し） │  │
│  └──────────────────┘  │
│  [ (8) 話しかける…  ][送信] │
│                (9)VOICEVOX:WhiteCUL │
└───────────────────────────┘
```

### 2.2 項目

| No | 項目 | 種類 | 内容・動作 |
|---|---|---|---|
| 1 | LLM ランプ | 表示 | 緑: LiteLLM が答えている / 黄: 答えが遅い / 灰: つながらない・失敗している |
| 2 | ROS ランプ | 表示 | 緑: rosbridge に接続中 / 灰: 切れている（自動で再接続） |
| 3 | CAMERA ランプ | 表示 | 緑: 人を検出中 / 黄: カメラは動いているが人はいない / 灰: カメラから2秒以上通知が無い |
| 4 | MIC ランプ | 表示 | 声を使うときだけ出る。緑: 聞いている / 黄: 声を聞き取り中・文字にしている / 灰: マイクが使えない |
| 5 | 話す / 黙る | ボタン | 緑のスピーカーで「話す」、灰色に×で「黙る（残り○分）」。押すと切り替える（機能仕様書 F-03） |
| 6 | 律 | 3D 表示 | VRM モデル。モーション48種類・表情8種類・まばたき・呼吸・髪の揺れ。目線と体が人を追う。カメラワーク（のぞき込み・胸から上へ寄る） |
| 7 | 字幕 | 表示 | 律の言葉を大きな文字で出す（顔を隠さない画面下側）。LLM に問い合わせ中は「・・・」 |
| 8 | チャット入力 | 入力・ボタン | 文字で話しかける。Enter か「送信」で送る |
| 9 | クレジット | 表示 | 声を使うとき「VOICEVOX:WhiteCUL」（VOICEVOX の利用条件） |

### 2.3 URL のパラメータ

| パラメータ | 意味 |
|---|---|
| `kiosk=1` | キオスク表示。`/ritsu/chat_user` に応答し、声で話し、台車へ指示を出すのはこの画面だけ |
| `lite=1` | 軽量描画（解像度0.75倍・アンチエイリアス無し・花びら無し・単純な材質）。UNO Q の GPU が固まらないよう必須 |
| `voice=1` / `voice=0` | 声を使う / 使わない（既定は kiosk のときだけ使う） |
| `model=chat-large` | LLM のモデルを一時的に切り替える |
| `capture=script` | マイクを古い方式（ScriptProcessor）で取り込む（聞こえないとき） |
| `needperson=0` | 人が映っていなくても聞く |
| `pr=` / `aa=` / `pet=` / `sm=` | 解像度の倍率・アンチエイリアス・花びらの数・単純な材質を個別に指定 |

### 2.4 状態による表示の変化

| 状態 | 表示 |
|---|---|
| 返事を考え中 | 字幕に「・・・」（話しかけへの返事はすぐ、独り言・反応は0.4秒たっても答えが無いとき） |
| 話している | 字幕を出し、声の大きさに合わせて口を動かす |
| 相手が話している | 聞く姿勢で小さくうなずく |
| 静かにしている | (5) が灰色に×と残り時間 |
| 人がいない | 一定の間隔で独り言・ダンス・のぞき込み |

## 3. SC-02 入力ページ（/remote）

### 3.1 レイアウト

```
┌──────────────────────────────┐
│ 律と話す  [覚えたこと][マイク][動かす][マスター登録] ●接続 │ ← (1) ヘッダー
├──────────────────────────────┤
│ (2) 開いたパネル（1つずつ）                │
│   マスター登録 / 覚えたこと / マイク / 動かす │
├──────────────────────────────┤
│ (3) 会話の履歴                            │
│   自分: こんにちは                          │
│   律: こんにちは！今日はいい天気ですね       │
│   声で: ついてきて                          │
│   ・・・（考え中）                          │
├──────────────────────────────┤
│ [ (4) 話しかける…              ][送信]     │
└──────────────────────────────┘
```

スマホの幅では「マスター登録」は「顔登録」と短く出し、接続の文字は隠して点だけにする。

### 3.2 ヘッダー

| No | 項目 | 種類 | 内容・動作 |
|---|---|---|---|
| 1-1 | タイトル | 表示 | 「律と話す」 |
| 1-2 | 覚えたこと | ボタン | 覚えたことのパネル（3.4）を開く・閉じる |
| 1-3 | マイク | ボタン | マイクのパネル（3.5）を開く・閉じる |
| 1-4 | 動かす | ボタン | 動かすパネル（3.6）を開く・閉じる |
| 1-5 | マスター登録 | ボタン | マスター登録のパネル（3.3）を開く・閉じる |
| 1-6 | 接続 | 表示 | rosbridge との接続。「接続中…」→ 接続できたら緑 |

### 3.3 マスター登録パネル

| 項目 | 種類 | 内容・動作 |
|---|---|---|
| 説明 | 表示 | カメラの正面で顔を向けたまま「登録」を押して約4秒じっとする。画像は保存せず数値だけを保存する |
| 登録 | ボタン | `/ritsu/enroll` `{"action":"add"}` を送る（約4秒で6枚） |
| 登録を消す | ボタン | `{"action":"clear"}` を送る |
| 状態 | 表示 | 「送信しました…」→ `/ritsu/enroll_status` の内容（登録中・できた・失敗・消した・枚数）。送れないときは「つながっていません」 |

### 3.4 覚えたことパネル

| 項目 | 種類 | 内容・動作 |
|---|---|---|
| 律のこと | 一覧・入力 | 律が自分について言ったこと。各行に「直す」「消す」。入力欄（40文字まで、例: 好きな食べ物はいちご）＋「足す」 |
| マスターのこと | 一覧・入力 | マスターが自分について言ったこと。同上（例: 猫を飼っている） |
| 教えた言葉 | 一覧・入力 | 言葉（30文字まで）と意味（80文字まで）＋「足す」 |
| 説明 | 表示 | 会話でも教えられること、間違いの直し方 |

- 一覧は `/ritsu/memory` から作る。空のときは「まだありません」。
- 直す・消す・足すは `/ritsu/memory_edit` で画面の律へ送り、律が記憶を書き換えて memory ノードへ保存する。

### 3.5 マイクパネル

| 項目 | 内容 |
|---|---|
| 状態 | 「律の画面からの知らせを待っています…」。3秒以上来ないと「律の画面から知らせが来ていません（声を使っていないか、止まっている）」 |
| 音の大きさ | 今の音量のバーと、声とみなす大きさの印 |
| 聞いている | 聞いているか（返事を考え中・言葉を守る間は聞かない） |
| 最後に聞いた | 最後に文字にした言葉 |
| 捨てた | 短すぎる音（咳・物音）や、雑音から Whisper が作りがちな文として捨てたもの |
| 失敗 | 文字起こしの失敗 |
| マイク | 使っているマイクの名前 |

`/ritsu/voice_status`（1秒ごと）から作る。

### 3.6 動かすパネル

| 項目 | 種類 | 内容・動作 |
|---|---|---|
| 停止 | ボタン（赤） | 律を通さず台車へ直接止める指示を送る。おさんぽ・フォローもやめる |
| 十字ボタン | ボタン ×7 | ↺（左回り）・前・↻（右回り）・左・止・右・後。押している間だけ `/cmd_vel` を送る。離すと止まる |
| 速さ | ラジオ | ゆっくり（0.1m/s）/ ふつう（0.2m/s） |
| 人の方を向く | チェック | `/ritsu/turn_enable` |
| こっちを向いて | ボタン | `/ritsu/turn` を送り、今いる人の方を向かせる |
| おさんぽ | チェック | `/ritsu/walk` `{"on":true/false}` |
| フォロー | チェック | `/ritsu/follow` `{"on":true/false,"sec":300}` |
| 状態 | 表示 | `/ritsu/base_status` から作る（下の表）。3秒以上来ないと「台車のノードから知らせが来ていません」 |
| 1輪ずつ試す | 折りたたみ・ボタン ×4 | 左前・右前・左後・右後を1秒だけ「前へ進む向き」に回す（`/ritsu/base_test`）。台車を浮かせて試す |

**状態の表示**

| 台車の状態 | 表示 |
|---|---|
| フォロー中 | 「フォロー中（ついていく人を探している / ついていっている / 近いので待っている / …・人まで 0.85m）」 |
| おさんぽ中 | 「おさんぽ中（進んでいる / 左へ向きを変えている / 右へ向きを変えている / 人の方へ向かっている / 次の向きを考えている）」 |
| 人の方を向いている | 「人の方を向いています」 |
| 少し動いている | 「少し動いています（前 / 後ろ / 左 / 右）」 |
| 1輪を試し回し中 | 「左前を試し回し中」など |
| それ以外 | 「つながっています」 |

あわせて、4輪の速さ、B 相で向きを読めている車輪、障害物の距離（「障害物[m] 前 0.32 左 - 右 1.10（前に近いので進みません）」）を出す。

### 3.7 会話の履歴と入力

| 項目 | 内容 |
|---|---|
| 履歴 | 自分の言葉、律の言葉（`/ritsu/say`）、ほかの人の言葉（「画面から」「声で」「ほかの人」と出所を付ける）。空のときは「話しかけると、画面の律が答えます。」 |
| 考え中 | `/ritsu/thinking` が true の間「・・・」を動かす |
| 入力欄 | 200文字まで。空のときは「送信」を押せない |
| 送信 | `/ritsu/chat_user` `{"text","from":<このページの ID>}` を送る |

## 4. SC-03 確認用カメラ画像

- `.env` で `DEBUG_SNAPSHOT=1` にしたときだけ、5秒ごとに検出枠付きのカメラ画像を `renderer/debug/camera.jpg` に保存し、`/debug/camera.jpg` で見られる。
- LAN 内の誰でも見られるので、確認が終わったら `DEBUG_SNAPSHOT=0` に戻す。
